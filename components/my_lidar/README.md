# 雷达模组通信协议文档

## 概述

本文档描述了雷达模组的串口通信协议，包括系统控制、人体检测、生理监测（心率、呼吸）、睡眠监测及 OTA 升级等功能。

## 协议帧格式

| 字段 | 长度 | 说明 |
|------|------|------|
| 帧头 | 2 Bytes | 固定为 `0x53 0x59` |
| 控制字 | 1 Byte | 控制类型标识 |
| 命令字 | 1 Byte | 具体命令标识 |
| 长度标识 | 2 Bytes | 数据长度（大端格式） |
| 数据 | N Bytes | 实际数据内容 |
| 校验码 | 1 Byte | 从帧头到数据的所有字节之和的低字节 |
| 帧尾 | 2 Bytes | 固定为 `0x54 0x43` |

### 校验码计算示例

以存在信息查询为例：

**指令构造：**
- 帧头：`0x53 0x59`
- 控制字：`0x80`
- 命令字：`0x81`
- 长度标识：`0x00 0x01`
- 数据：`0x0F`
- 帧尾：`0x54 0x43`

**校验码计算：**
```
sum = (0x53 + 0x59 + 0x80 + 0x81 + 0x00 + 0x01 + 0x0F) = 0x01BD
取低字节：sum = 0xBD
```

**完整指令：** `53 59 80 81 00 01 0F BD 54 43`

| | 回复 | `5359 84 96 0001 1B 时间 sum 5443` | 数值范围：5-120<br>单位：分钟 |
| 挣扎状态判读查询 | 下发 | `5359 84 9A 0001 0F sum 5443` | |
| | 回复 | `5359 84 9A 0001 (00/01/02) sum 5443` | 00：灵敏度低<br>01：灵敏度中(默认)<br>02：灵敏度高<br>需配合固件使用 |

## 9. OTA 固件升级

| 功能 | 方向 | 指令格式 | 说明 |
|------|------|----------|------|
| 开始OTA升级 | 下发 | `5359 03 01 0004 4B 固件包大小 sum 5443` | 例如：固件大小为150K(150×1024 byte)时，4B的内容为: 00 02 58 00（大端在前） |
| | 回复 | `5359 03 01 0004 4B 每帧传输升级包大小 sum 5443` | 上位机将按照此处回复的大小来确定每帧需要下发多长的固件包信息 |

| | 回复 | `5359 03 02 0001 (01/02) sum 5443` | 01：接收成功<br>02：接收失败 |
| 结束OTA升级 | 下发 | `5359 03 03 0001 (01/02) sum 5443` | 01：固件包发送完成<br>02：固件包发送未完成 |
| | 回复 | `5359 03 03 0001 01 sum 5443` | |

## 附录

### 注释说明

- **1B**：1字节（Byte）
- **2B**：2字节（Byte）
- **len**：数据长度字段
- **sum**：校验码，需要根据实际数据计算
- **0F**：查询指令中常用的数据字段
- **(xx/yy)**：表示可选值，如 (01/00) 表示可以是01或00

### 开发建议

1. 所有多字节数据采用**大端格式**（高字节在前）
2. 校验码为从帧头到数据的所有字节之和的**低字节**
3. 上报方式说明：
   - **状态变化时上报**：当检测到状态改变时立即上报
   - **定时上报**：按固定时间间隔定期上报
4. 建议实现超时重传机制，确保通信可靠性
5. 注意处理波形数据的中轴线（128），用于还原实际波形
