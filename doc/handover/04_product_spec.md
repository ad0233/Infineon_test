## 5. 雷达罩 / 雷达可见窗口（CRITICAL 硬约束）

> **本节是整份规格书最容易做错、做错就报废的部分。结构组在出第一版 3D 之前必须读完。**

### 5.0 摆放基准与俯仰角推导

整机本体高 30 cm，雷达 IC 在设备顶部，**放在床头柜上面，朝向床上仰卧的人**。

| 市场 | 床面距地 | 床头柜面距地 | 雷达绝对高度 | 仰卧胸口高度 | 雷达高于胸口 | 推荐俯仰 |
|------|---------|------------|-----------|-----------|-----------|---------|
| **北美** | 61–76 cm（典型 63.5） | 58–71 cm（≈ 床面 ±5） | **床面 + 30 cm ≈ 93 cm** | 床面 + 15 cm ≈ 78 cm | **+15 cm** | **−15°（固定）** |
| 亚洲（榻榻米 / 矮床 + 高床头柜） | 25–80 cm（跨度大） | 50–75 cm（与床面可能反差大） | 80–105 cm | 35–95 cm | −5 ~ +55 cm | **−10° / −25° / −40°（三档）** |

水平距离假设 60 cm。北美主流场景一档固定可覆盖；亚洲 SKU 需多档或软件校准（DVT 待决）。

### 5.1 物料约束

| 项 | 要求 | 说明 |
|----|------|------|
| **雷达罩材料** | PC、ABS、PC+ABS、PMMA 任一 | **禁止纤维填充（玻纤/碳纤）** |
| **雷达罩厚度** | **建议 1.0 mm ± 0.1 mm**，最大 2.0 mm | 60 GHz 在 PC 中 λ/2 ≈ 1.5 mm；过厚会引入驻波损耗 |
| **罩面平整度** | 雷达正面 ±20 mm 范围内**无加强筋、无内壁螺柱、无熔接线** | 这些会成为反射面/二次散射源 |
| **涂层 / 喷漆** | **禁止金属漆、镭射漆、IMD 金属膜、电镀** | 60 GHz 几乎完全被金属反射 |
| **丝印 / Logo** | 雷达正前方禁止 | LOGO 放罩面外侧、避开雷达开角范围 |
| **装饰条** | 任何金属装饰条距雷达 IC 中心 ≥ 25 mm 且不在 ±45° 锥内 | |

### 5.2 几何约束

```
                    俯视
                ┌─────────────┐
                │             │
                │  雷达 IC ●  │ ← 板载位置
                │      ╱│╲    │
                │     ╱ │ ╲   │ ← ±45° 主波束锥
                │    ╱  │  ╲  │
                └───┴───┴───┴─┘
                    ↓
            朝向用户胸口
```

| 项 | 要求 |
|----|------|
| **天线开角** | 主瓣 ±45°（方位 + 俯仰），**整个锥形空间内不能有金属** |
| **罩到 IC 距离** | 0 mm（贴合）或 ≥ 5 mm（避开近场）；**禁止 1–4 mm 之间** | （会引起多次反射） |
| **IC 到顶壳距离** | ≤ 8 mm（推荐），最大 15 mm | 距离越远辐射衰减越多 |
| **罩与 IC 之间** | 不能有屏蔽罩、铜片、CPU 散热片、扬声器磁铁 | 都会反射 / 阻挡 |
| **天线指向（北美 SKU）** | **俯仰 −15°（向下）** | 整机本体 30 cm + 床头柜 ≈ 床面 ±5 cm 的北美基准下，雷达高于仰卧胸口 ≈ 15 cm，水平 60 cm，atan(15/60) ≈ −14° |
| **天线指向（亚洲 SKU）** | 三档铰链 **−10° / −25° / −40°** | 榻榻米/矮床/高床头柜组合下高差跨度大，需多档（DVT 待定） |

### 5.3 罩面以外的金属约束

| 项 | 要求 |
|----|------|
| 屏蔽罩 / 金属背板 | 雷达 IC 正背面**保留 ≥ 30 mm 净空** |
| 喇叭磁铁 | 距雷达 IC 中心 ≥ 50 mm |
| 充电线圈 / NFC（如果加） | **不允许放在雷达视野侧** |
| ESP32 屏蔽罩 | 不要罩到雷达 IC 上方；雷达 IC 单独不屏蔽 |

### 5.4 验证方法

DVT 第一版结构件回来后，按下面步骤验证（可用现有 panel GUI）：

1. 不带壳裸板，距离 80 cm 仰卧测试，记录 panel GUI 中 distance / breath / heart 曲线 60 s
2. 装上 DVT 外壳，**同位置同姿势**，再测 60 s
3. 对比：
   - distance 曲线**最大偏差 ≤ 5 cm**
   - breath BPM 稳态偏差 ≤ 2 BPM
   - heart BPM 稳态偏差 ≤ 5 BPM
   - confidence 曲线均值下降 ≤ 0.1
4. 任何一项不达标 → 拆罩看金属/厚度/装饰条/筋位，按 §5.1–5.3 排查

工具：`tools/sleep_analyze.py`（unified panel GUI），CSV 录制对比。

### 5.5 已知坑（不要再踩）

- 第一版打样**罩面贴了 IMD 金属膜** → 信号完全消失（已有教训）
- 罩内壁加强筋距 IC 太近 → 距离曲线出现 30 cm 处假目标
- 喇叭磁铁正对雷达 → confidence 永远 < 0.5

## 11. 已冻结（不可改）

- 主控选型：ESP32-P4
- 雷达选型：BGT60TR13C（60–63 GHz, BW 4 GHz, 3 RX）
- 雷达 SPI 引脚：GPIO0/1/3/5（已固化在固件）
- 雷达初始化时序：FIFO 6×4096 分片读取、SPI ≥ 25 MHz（违反则崩溃，详见 `CLAUDE.md`）
- 单房间绑定原则：APP 调度只命中绑定的卧室一个房间
- 隐私闸：物理切断雷达供电（不可改成软件 mute）
- B 域断网行为：必须本地闭环

任何对上述项的改动需要**软硬件 + 算法 + ID 三方签字**。
