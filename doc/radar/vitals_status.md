## 关键参数速查

| 参数 | 值 | 位置 |
|------|-----|------|
| 帧率 fs | 10 Hz | `RADAR_PRESENCE_FRAME_RATE_HZ` |
| 历史长度 | 200帧 = 20s | `RADAR_PRESENCE_HISTORY_LEN` |
| FFT 大小 | 1024点 | `RADAR_VITALS_FFT_SIZE` |
| FFT 频率分辨率 | 0.00977 Hz/bin | fs / fft_n |
| 呼吸有效范围 | 12.0 ~ 30.0 BPM | ROI: 0.20-0.50 Hz |
| 心率有效范围 | 51.0 ~ 132.0 BPM | ROI: 0.85-2.20 Hz |
| 相位差分裁剪 | ±0.30 rad | `RADAR_PHASE_DIFF_CLIP` |
| 呼吸平滑窗口 | 7点 | `RADAR_PHASE_SMOOTH_LEN` |
| 估算间隔 | 200帧 = 20s | `RADAR_VITALS_INTERVAL_FRAMES` |
| 心率离群拒绝 | ±25 BPM (count≥3后) | `radar_estimate_vitals()` |
| 波形输出频率 | 10Hz (每帧) | 实时IIR |
| BPM输出频率 | 0.05Hz (每20s) | filtfilt + FFT |
