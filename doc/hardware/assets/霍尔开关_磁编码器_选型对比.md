# 传感器选型参照

**霍尔开关 vs 磁编码器 — 毫米波雷达限位/角度检测应用**

版本：2025-05 | 适用场景：雷达上下/左右摆动调节机构

---

## 一、核心功能对比

| 维度 | 霍尔开关 | 磁编码器（AS5600） |
|------|----------|-------------------|
| 输出类型 | 数字开关量：HIGH / LOW | 连续角度值：0°–360°，分辨率 0.088° |
| 告知信息 | 是否超过阈值（到位 / 未到位） | 当前精确角度（可持续读取） |
| 接口 | 1 根 GPIO | I²C（SDA + SCL） |
| 磁铁安装 | 任意位置贴附，偏移不影响 | 必须同轴安装在转轴末端，偏心误差 < 0.5 mm |
| 供电 | 2.5–38 V（DRV5023） | 3.3 V / 5 V |
| 单颗成本 | ¥0.1–2 | ¥5–15 |
| 外围元器件 | 100 nF 去耦电容（推挽输出无需上拉） | 100 nF 去耦 + 4.7 kΩ I²C 上拉电阻 × 2 |

---

## 二、适用场景判断树

| 需求描述 | 推荐方案 |
|----------|----------|
| 只判断「是否到达某个固定位置」 | 霍尔开关 |
| 需要知道「当前在哪个角度」并记录 | 磁编码器 |
| 做闭环电机控制，精确停在指定角度 | 磁编码器 |
| 雷达手动调节后锁死，系统不关心角度 | **两者均不需要，纯机械锁紧即可** |
| 有电机驱动 + 需要硬件安全限位（防冲出） | 霍尔开关做限位保护 + 磁编码器做角度反馈 |
| 雷达数据与空间角度绑定（点云建图） | 磁编码器（必须） |

## 三、推荐型号规格

### 3.1 霍尔开关 — DRV5023（TI）

| 参数 | 规格 |
|------|------|
| 供电电压 | 2.5 V – 38 V |
| 输出类型 | 推挽 Push-Pull（无需上拉电阻，直连 GPIO） |
| 工作温度 | -40°C ~ +150°C |
| 封装 | SOT-23（3 引脚：VCC / GND / OUT） |
| 灵敏度选型 | A 档（1 mT，触发距离约 8–15 mm）— 限位首选；E 档（25 mT）适合强磁干扰环境 |
| 输出逻辑 | 无磁 = HIGH（1）；磁铁靠近 = LOW（0） |
| 参考价格 | ¥1–2 / 颗（贸易商） |

**灵敏度档位对照：**

| 档位 | 完整型号 | Bop 触发 (mT) | Brp 释放 (mT) | N35 磁铁触发距离 | 推荐场景 |
|------|----------|--------------|--------------|-----------------|----------|
| **A ← 推荐** | DRV5023AJLPGM | −1.0 | +1.0 | 约 8–15 mm | 雷达限位首选，小磁铁即可 |
| B | DRV5023BJLPGM | −2.5 | +2.5 | 约 5–10 mm | 通用 |
| C | DRV5023CJLPGM | −5.0 | +5.0 | 约 3–7 mm | 通用 |
| D | DRV5023DJLPGM | −12 | +12 | 约 2–4 mm | 抗杂散磁场 |
| E | DRV5023EJLPGM | −25 | +25 | 约 1–3 mm | 强磁干扰环境 |

> 触发距离以 10×5×3 mm N35 钕铁硼、面磁对准传感器正面为参考。

### 3.2 磁编码器 — AS5600（ams OSRAM）

| 参数 | 规格 |
|------|------|
| 供电电压 | 3.3 V / 5 V |
| 分辨率 | 12-bit（4096 步/转），角度分辨率 0.088° |
| 接口 | I²C（地址固定 0x36）；PWM 模拟量输出（可选） |
| 工作温度 | -40°C ~ +125°C |
| 封装 | SOIC-8 / QFN-8 |
| 磁铁要求 | 直径 6 mm 圆柱形磁铁，同轴安装，间距 0.5–3 mm |
| 零位设置 | 可编程写入 ZPOS / MPOS 寄存器定义 0° 基准 |
| 参考价格 | ¥8–15 / 颗（贸易商） |

> AS5600 I²C 地址固定为 0x36，同一总线只能挂一颗。多轴场景需分开 I²C 总线或选 AS5048B（支持地址配置）。

## 四、外围电路要点

### 4.1 DRV5023 最简电路

```
VCC ──┬──[100nF]── GND
      │
   [DRV5023]
      │
     OUT ──[10kΩ 可选]── MCU GPIO（Input，不加内部上拉）
      │
     GND ────────────── MCU GND（共地）
```

- 推挽输出，**不加上拉电阻**
- STM32 CubeMX：GPIO Pull-up/down 设为 **No pull**
- 10 kΩ 串联电阻可选，用于 GPIO 口 ESD 保护

### 4.2 AS5600 最简电路

```
VCC ──┬──[100nF]── GND
      │    ├──[4.7kΩ]── SDA
      │    └──[4.7kΩ]── SCL
   [AS5600]
      ├── SDA ── MCU I²C SDA
      ├── SCL ── MCU I²C SCL
      ├── DIR ── GND（顺时针为正）或 VCC（逆时针为正）
      └── PROG ── 悬空（正常使用）
```

- 3.3 V 系统上拉 4.7 kΩ；5 V 系统可用 2.2 kΩ
- I²C 速率建议 100 kHz（Standard Mode）

## 五、安装注意事项

| 项目 | DRV5023 霍尔开关 | AS5600 磁编码器 |
|------|-----------------|----------------|
| 磁铁类型 | 10×5×3 mm N35 矩形钕铁硼 | Φ6×2.5 mm 圆柱轴向充磁（随模块附赠） |
| 安装位置 | 固定在支架任意位置，磁铁贴摆臂 | 磁铁必须同轴贴在转轴末端，传感器正对其下方 |
| 间距要求 | 磁铁正面距传感器 2–5 mm，A 档最宽松 | 轴向间距 0.5–3 mm；偏心误差 < 0.5 mm |
| 抗振动 | 无接触，天然抗振动 | 无接触，但偏心量随振动变大会引入误差 |
| 调试方法 | 串口打印 GPIO 电平，靠近/远离验证 | I²C 读 RAW_ANGLE 寄存器（0x0C/0x0D）实时观察角度 |

## 六、本项目结论

当前毫米波雷达上下摆动机构为用户手动调节、锁定后固定，系统运行时不需要读取角度值。

| 方向 | 结论 |
|------|------|
| 上下调节（手动 + 锁死） | **不需要任何传感器**。改善重点：机械锁紧结构（弧形槽 + 蝶形螺母或双点锁紧），防振动跑位。 |
| 左右调节（手动 + 锁死） | 同上，不需要传感器。如需用户参考，弧形槽旁刻角度刻度盘即可。 |
| 若后续加入电机驱动 | 上下限位：DRV5023A（硬件安全保护）；角度反馈：AS5600（闭环控制 / 点云标注） |

> 若用户校准时需要参考角度，在弧形槽旁加刻度盘成本接近零，优先于增加传感器。
