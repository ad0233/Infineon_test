## 1. 概述 Overview

VEML7700 是 Vishay 高精度环境光传感器，内置 Filtron™ 技术，光谱响应曲线与人眼视觉函数 CIE V(λ) 高度吻合，峰值响应约 555 nm，有效响应范围 400 ~ 950 nm（参见 Datasheet Rev.1.4，Doc No. 84286，Fig.2）。

本规格书用于定义睡眠闹钟产品中，覆盖于 VEML7700 传感器上方的结构镜片的光学、机械、材料及可靠性要求，供镜片供应商开发、样品确认及批量交付使用。

**等级说明：**

- `【必须】` — Mandatory，量产验收硬性要求
- `【建议】` — Recommended，强烈建议满足
- `【参考】` — Reference，设计参考，可协商

## 4. 材料要求 Material Requirements

| 参数 Parameter | 要求 Requirement | 等级 |
|---|---|---|
| 基材 Base material | 光学级 PC（聚碳酸酯）或光学级 PMMA；**不得**使用普通工业级原料 | 【必须】 |
| 颜色 Color | 烟熏灰 / 深灰，透光率 20 ~ 40%；具体色号与买方确认样品后冻结 | 【必须】 |
| 环保认证 RoHS/REACH | 符合 RoHS 2.0 / REACH，需提供材料成分报告（MDR） | 【必须】 |
| 阻燃等级 Flammability | UL94 V-0 或以上 | 【建议】 |
| 遮光侧壁处理 | 镜片四周侧面喷涂或印刷黑色 BM 油墨，防止侧向漏光 | 【建议】 |

## 5. 环境可靠性 Environmental Reliability

| 测试项 Test Item | 测试条件 Condition | 验收标准 Acceptance Criteria | 等级 |
|---|---|---|---|
| 工作温度范围 | -10 ~ +60 °C | 透光率变化 ≤ ±3%，无变形 | 【必须】 |
| 储存温度范围 | -25 ~ +85 °C | 外观无裂纹、黄变，透光率无明显衰减 | 【必须】 |
| 湿热老化 | 85 °C / 85% RH，168 h | 透光率衰减 ≤ 5%，无起雾、分层 | 【建议】 |
| UV 耐候 | UVB 340 nm，200 h | 色差 ΔE ≤ 2，透光率衰减 ≤ 5% | 【建议】 |
| 回流焊耐热 | Peak 260 °C（参考 J-STD-020） | 尺寸变形 ≤ 0.05 mm（若镜片随 PCB 过炉） | 【参考】 |
