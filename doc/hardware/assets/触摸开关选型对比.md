# BY-SA-V001 触摸滑条方案（音量 / 光照）

> 板号：BY-SA-V001 / 项目：BY001-ESP32（Lunawake 床头硬件）
> 用途：金属面板上的两段线性滑条 —— 音量、光照亮度
> 状态：方案对照阶段，待 PM / ID 决策；推荐方向：金属背贴电容触摸 + LED 灯柱 + 线性马达

---

## 1. 设计目标

| 目标 | 要求 |
|------|------|
| 主控件 | 两段线性滑条（音量 / 光照） |
| 面板材质 | 金属（铝合金或不锈钢） |
| 工业感 | 正面无开孔、无明显减薄痕迹 |
| 体验 | 滑动感连续无台阶；具备"按下感"反馈 |
| 防误触 | 床沿/手臂误碰可过滤 |
| 量产 | BOM 可控、装配公差宽容 |
| 寿命 | ≥ 10⁷ 次操作 |

约束来源：金属面板的工业感与床头使用环境共同决定 —— 不能开孔（破工业感）、不能裸塑料（破质感）、用户大概率躺着摸（误触多）。

## 2. 推荐结论（给 PM 的一行）

> **金属背贴电容触摸阵列 + LED 灯柱视觉反馈 + 线性谐振马达 (LRA) 振动反馈** 是综合最优解。
> 仅在 ID 坚持金属厚度 ≥ 1mm 且整面禁止减薄时，再考虑电容压感方案。

## 4. 推荐方案：金属背贴电容触摸滑条

### 4.1 核心原理 —— 重心插值 (Centroid Interpolation)

人手指接触面 8–12mm，比单个电极宽。手指同时压在 2–3 个相邻电极上，每个电极的电容变化量 ∝ 手指中心到电极中心距离的反函数。把多通道电容值做加权重心，即可把位置插值到远超电极物理间距的精度。

```
电极物理间距 7.5mm；插值后位置精度 < 0.3mm/级。
```

### 4.2 电极几何 —— 两种典型 pattern

**方案 A：互补锯齿 / Sawtooth（2 通道）**

```
   ／＼／＼／＼／＼／＼／＼／＼／＼   ← A 通道
   ＼／＼／＼／＼／＼／＼／＼／＼／   ← B 通道
   |←──────  60mm  ──────→|

position = L × C_B / (C_A + C_B)
```

只需 2 个 ADC 通道。Microchip / TI 应用手册中的 saw-tooth slider 即此方案。走线少、便宜，适合 MCU 自带触摸通道少的情况。

**方案 B：N 段离散电极 + 加权重心（推荐）**

```
[E1][E2][E3][E4][E5][E6][E7][E8]   ← 6–10 个等分矩形电极
```

读出所有电极 ΔC，找峰值电极 k，仅用 k 及左右邻居算重心：

```
position = (k-1)·ΔC_{k-1} + k·ΔC_k + (k+1)·ΔC_{k+1}
          ─────────────────────────────────────────
                ΔC_{k-1} + ΔC_k + ΔC_{k+1}

output = position × (256 / N_electrodes)
```

Azoteq / Cypress / Microchip 商用滑条控制器均按此实现。

### 4.3 256 级分辨率推导

| 项 | 典型值 |
|---|---|
| 单电极手指接触 ΔC | 1–3 pF |
| 电容测量方式 | 电荷转移 (CSD/CVD)，等效 14–16 bit ADC |
| 实测 SNR | 60–80 dB |
| 重心计算输出 | 浮点 → 量化到 8 bit (256 级) |
| 物理长度 60mm × 8 电极 | 每级 = 0.23 mm |
| 人手感知阈值 | ~1 mm |

→ 用户主观感受为完全连续。真正卡分辨率的不是 ADC 位数，而是**噪声基底**和**金属耦合寄生电容**。

### 4.4 算法清单（缺一就抖）

1. **基线追踪**：每电极慢速 IIR（τ = 5–30s）跟踪环境基线；触摸期间冻结。
2. **差分电容 ΔC = C_raw − C_baseline**：所有判定与重心都用差分。
3. **迟滞门限**：进入阈值 Th_on > 退出阈值 Th_off，防边界抖动。
4. **邻居截断**：只取峰值 ±1 三个电极算重心，远端电极不参与（避免远耦合拖偏）。
5. **输出滤波**：一阶 IIR α = 0.2–0.3 + ±1 级死区；快速滑动时自适应放大 α 跟手。
6. **释放锁存**：手指离开瞬间 ΔC 雪崩衰减会算出乱码位置；检测 ΔC_total 突降即锁存上一帧，进入 idle。

### 4.5 金属背贴专门要做的事

普通 PCB 触摸到金属背贴还需要额外处理：

- **Driven Shield（主动屏蔽）**：金属面板本体接地或浮空都不行 —— 会形成大寄生电容把信号吞掉。控制器需输出与电极**同相位同幅值**的方波驱动金属面板/屏蔽层，中和寄生电容。Azoteq 叫 ProxFusion、Cypress 叫 SmartSense、TI 叫 Shield Driver。
- **金属减薄**：电极对应位置背铣到 0.3–0.5mm（局部，工业感不破）。
  - ≤ 0.5mm：信号充足，余量大
  - 0.5–0.8mm：勉强可用，需精细调参
  - ≥ 1.0mm：基本不可行
- **电极 PCB 距金属间距**：0.1–0.3mm，泡棉胶 / 双面胶 / 灌胶固定；太远信号弱、太近压不平。
- **原位校准 (in-situ)**：必须装到金属面板里再校准，不能在裸 PCB 上校准（寄生电容差一个数量级）。

## 5. 备选方案：压感滑条（参考）

### 5.1 电容压感（推荐压感路线选这个）

原理：金属面板下放 0.2–0.5mm 弹性介质（硅胶/泡棉）+ 电容传感层。按压使弹性层压缩，电极间距变化 → 电容变化 → 力测量。

- 优点：金属厚度不敏感、误触率极低、力阈值天然防误触、最接近实体按键手感。
- 缺点：BOM 高（弹性件 + 力传感 + 校准工序）；弹性件疲劳寿命 10⁵–10⁶ 次；装配公差敏感（弹性件压缩量、胶层厚度都影响标定），量产良率风险高。
- 代表实现：iPhone Force Touch 时代的 Taptic Engine 组合方案；Apple 触控板。
- 参考器件：NextInput ForceTouch、UneoTech 力膜、Microchip 配套压感方案。

### 5.2 FSR（力敏电阻）/ 应变片（不推荐，仅作记录）

- **FSR**：聚合物力敏膜片，按压电阻下降。便宜但温漂迟滞大、寿命 10⁵ 次以下、用作滑条需阵列且标定难。
- **应变片**：金属面板必须有可测形变。床头面板尺寸下，1mm 以上金属在手指力下形变量 < 1μm，应变片 SNR 不够。

仅在低成本、非高频使用的开关型场景考虑 FSR；滑条不要用。

### 5.3 何时该选压感而非电容

**任一条件成立**再考虑压感：

1. ID 拒绝任何金属减薄（要求面板整面等厚 ≥ 1mm）。
2. 滑条位置经常被无意触碰（如紧贴床沿），需要力阈值过滤而非软件 long-press。
3. 产品定位高端，能吸收弹性件 + LRA + 力传感全套 BOM 成本。
4. 用户群对"按键感"敏感（典型如老年用户，电容滑条"摸不到反馈"会被反馈"坏了"）。

## 6. 量产 / 工程化注意

| 项 | 注意点 |
|---|---|
| PCB 电极镀层 | ENIG 或喷锡均可；铜箔氧化不影响电容触摸 |
| 电极与金属间介质 | 双面胶 / 泡棉 / 灌胶；介质常数稳定，避免空气间隙（湿度敏感） |
| 装配公差 | 介质厚度 ±0.05mm 内；超出需逐机校准 |
| EMC | 金属面板需有低阻抗驱动屏蔽连接；不能孤立浮空 |
| 雷达共存 | 触摸 100–500 kHz 与 BGT60TR13C 60 GHz 完全错开，无频段冲突；注意 GND 平面分割不要切断 driven shield 回路 |
| ESD | 金属面板天然 ESD 路径；触摸控制器需 ±8kV 接触放电耐受（Azoteq/Cypress 均满足） |
| LED 灯柱共存 | 走线避开触摸电极正下方；LED 驱动 PWM 频率避开触摸扫描频率（典型 100 kHz） |
| LRA 共存 | LRA 振动不影响电容测量（频段差 100 倍以上） |

## 7. 决策建议

**第一步（本周）**：PM 确认两条信息
1. ID 能否接受金属面板局部减薄到 0.3–0.5mm？（决定电容 vs 压感）
2. 滑条物理位置是否会被睡姿误压？（决定是否需要力阈值过滤）

**第二步（决策后 2 周）**：
- 若走电容方案：采购 Azoteq IQS572 EVK + 定制金属面板样件，验证背贴 SNR 与重心稳定度。
- 若走压感方案：找 NextInput / UneoTech 拿样，做弹性介质 + 力传感叠层验证。

**第三步（验证通过后 4 周）**：定型 BOM，进入 V2 板布局，与 LED 灯柱 / LRA 同步设计。
