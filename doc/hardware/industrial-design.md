## 0. 一句话定位

放在床头，**夜间 60 cm – 150 cm 距离**用 60 GHz 毫米波雷达非接触检测呼吸心率，
配合 4 麦克风阵列、立体声助眠声景、暖光光柱，做入睡 → 整夜 → 唤醒的全链路助眠。
**必须可断网独立工作整夜**。

---

## 1. 用户姿态与场景

### 1.1 摆放基准（北美 SKU）

**整机本体高 30 cm，雷达 IC 位于设备顶部**，放在床头柜上。基于北美数据：

| 项 | 范围 | 来源 |
|---|---|---|
| 床面距地 | 61–76 cm（24–30 in），典型 **63.5 cm** | NA mattress survey |
| 床头柜顶面距地 | 58–71 cm（23–28 in） | NA furniture standard |
| 床头柜顶面 vs 床面 | ±5 cm（设计惯例） | — |
| **雷达 IC 绝对高度** | **床头柜面 + 30 cm ≈ 床面 + 30 cm** | 由整机高度推导 |
| 仰卧用户胸口高度 | 床面 + 12–18 cm | 解剖学常值 |
| **雷达高于胸口** | **12–18 cm**（中位 15 cm） | 推导结果 |
| 床头柜到床上胸口水平距离 | 30–80 cm，典型 60 cm | — |

### 1.2 主使用姿态

| 场景 | 用户位置 | 设备位置 | 直线距离（雷达→胸口） | 高度差（雷达−胸口） |
|------|---------|---------|------|--------|
| 入睡（windDown） | 床上半坐 | 床头柜 | 50–80 cm | **+5 ~ +20 cm**（雷达略高于胸口） |
| 整夜（asleep） | 仰卧 / 侧卧 | 床头柜 | 60–100 cm | **+12 ~ +18 cm** |
| 唤醒（wake） | 床上 | 床头柜 | 50–100 cm | 同上 |

**结构含义**：
- 雷达高于胸口 → 主波束**朝床面斜下方**，俯仰 **−10° ~ −20°（向下）**，北美 SKU **固定 −15°**
- 中国 / 亚洲（榻榻米 / 矮床 + 高床头柜）需要 **三档铰链：−10° / −25° / −40°**（DVT 待定）
- 设备整体重心要稳，**避免侧翻**；底部摩擦垫宽度 ≥ 整机宽度 70%
- **不允许设计成必须挂墙的形态**（不依赖墙面安装）

### 1.3 不可放置位置（用户行为约束 → 不强制结构防呆）

仅文案/说明书提示：空调出风口正下方、风扇正前、纱帘飘动范围内。
**结构无须做物理拒绝**。

## 2. 物理交互

### 2.1 弧形滑条 / 旋钮（结构与 ID 决定）

[luna-panel-bridge.md §7](luna-panel-bridge.md) 定义了 Auto / Manual 双语义。结构组需提供：
- **一个连续位置输入**（电容滑条 / 旋钮编码器 / 触摸环）— 软件按当前模式映射
- 操作过程**可单手完成**，无需视觉确认
- 手指离开 1.5 s 后**位置锁定不漂移**

**电气接口**：留 I²C / GPIO 各 2 路给滑条模块（具体器件由结构-ID 定后选型）。

### 2.2 隐私闸（CRITICAL）

- **物理切断雷达供电**——不是软件 mute，是断 VCC
- **APP 不可远程开启**，只能远程关闭并需机身二次确认
- 状态外显：RGB 红色稳态 = 关；熄灭 = 开
- 结构上必须能**单手 1 秒内触达**

## 3. 视觉反馈

### 3.1 RGB 状态灯（已上板：GPIO15 / 16 / 17，三色独立）

是**指示灯**，不是光柱。光柱另算（§3.2）。

| 颜色 | 含义 |
|------|------|
| 绿 呼吸 | 监测态，雷达在线 |
| 蓝 呼吸 | 助眠态-静默光 / 蓝牙配对 |
| 紫 慢闪 | 助眠态-语音引导中 |
| 黄 慢闪 | 唤醒态 |
| 红 稳态 | 隐私闸已关 / 故障 |
| 红 快闪 | 严重故障（雷达初始化失败、过温、电源异常） |

**结构要求**：
- 单一发光面，**不要 3 个分开的圆点**（用户会以为是 3 个独立指示灯）
- 透光面材料雾度足够，**LED die 不可见**
- 亮度上限：床头最暗环境下不刺眼，**最大轴向照度 ≤ 5 lx @ 50 cm**

### 3.2 暖光光柱（待结构 + ID 定型）

软件契约见 [luna-panel-bridge.md §6](luna-panel-bridge.md)，结构需支持：
- 光柱**与声景共相位**（蜡烛熄灭曲线），所以亮度 PWM 必须**稳定可调到 0.1% 以下**
- 光谱要求：**低 melanopic**（峰值压在褪黑素抑制阈下）— 用 1800 K – 2200 K 暖光 LED
- 朝向：**不直射用户眼睛**，建议向上/向床面 wash light，或漫射柱体
- 关闭时**完全无残光**（asleep 阶段整夜不亮）

光柱驱动当前主板**未预留**，DVT 需追加 PWM + 升压通道（详见 `04_product_spec.md §硬件接口扩展`）。

## 4. 音频体验

### 4.1 输出（立体声）

- 功放：U17，2×10 W AB/D 类
- 喇叭接口：CN4 / CN18（PicoBlade 1.25 mm 6P×2）
- 频响目标：**60 Hz – 18 kHz ±6 dB**（助眠声景需要 60 Hz 以下的低频底噪）

**结构要求**：
- 喇叭单元朝向**用户耳侧**（侧出声 / 顶出声），不要正对墙背或床面
- 音腔密封，**避免被动辐射器与外壳共振**产生嗡鸣（dB SPL ≤ 50 时容易听见）
- **MIC 阵列与喇叭物理距离 ≥ 30 mm**，且中间有结构隔挡，降低 AEC 难度

### 4.2 输入（4 麦阵列：MIC1–MIC4）

- 数字 MEMS，PDM 接口
- 用途：噪音 dB / 鼾声 / 婴儿啼哭检测，**不做语音命令词**
- 麦克风开孔：**Φ ≥ 0.8 mm，深度 ≤ 1.5 mm**，前腔体积越小越好
- 防尘网：透声织物，不要海绵
- **4 颗的几何排布由声学算法决定**，结构组先按 PCB 现有位置开孔，二次评审再调

### 4.3 婴幼儿场景（hard clamp）

- **dB SPL ≤ 50 @ 1 m**（声学结构需配合软件做总声压上限）
- **整夜白噪禁用**（软件层强约束，结构不需做拒绝）

## 5. 端口与接驳

| 端口 | 板上位号 | 用途 | 结构开孔约束 |
|------|---------|------|------------|
| USB-C | USB1 | 充电 + 数据 + OTA | 同侧或背面，**禁止用户面**；TYPE-C 16PIN 卧贴 |
| USB-A | USB2 | 下游（外接配件） | 直插 180°，**背面或底面** |
| 电源输入 | H1 | DC 主供电 PH2.0 卧贴 2P | **不外露**，结构内部 |
| 电池/可选 | H2 | PH2.0 卧贴 2P | **不外露** |
| 喇叭 1 | CN4 | 6P PicoBlade | **不外露** |
| 喇叭 2 | CN18 | 6P PicoBlade | **不外露** |
| 调试 | CN2 / U13 | 8P 1.25 / 2×4 排针 | **隐藏在底部脚垫下或盖板内**，量产前评估是否拆除 |

**重要**：USB-A 是供电输出 ≤ 1.5 A，不要把它放在用户**摸不到的内部**。

## 7. 装配 / 拆机

- 维修拆机**不暴露用户**：所有螺丝隐藏（脚垫下 / 盖板下）
- 主板**单板架构**（已确认），结构定位孔以 PCB 4 角 M2.5 为准（结构组按 PCB 出图确认）
- 雷达 IC（U? — BGT60TR13C）位置**优先靠近顶面**，距离顶壳 ≤ 8 mm，方便天线辐射

---

## 8. 验收触点（结构组完成后这些必须能跑通）

1. 床头黑暗环境，单手 1 秒内能摸到隐私闸键并关闭（红灯亮）
2. 设备放床头柜 80 cm 距离，仰卧时雷达 BPM 稳定 ≥ 60 s（说明波束未被外壳遮挡）
3. asleep 模式下用相机长曝光 5 s，整机面板无任何可见光（说明遮光合格）
4. 满音量播放粉噪 1 min，外壳无可闻共振
5. 1.5 m 跌落到地毯，外壳不开裂、按键不卡死、雷达功能不损坏
6. 连续 8 h 满载（雷达 + 音频 + Wi-Fi）后，外壳用户接触面温度 ≤ 45 ℃
