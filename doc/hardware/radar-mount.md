# Radar Mount 模块

> Status: 🟡 needs-decision · Last reviewed: 2026-05-18 · 北美 SKU 已定，亚洲 SKU + 是否电动化待决
>
> 雷达机械支架 / 俯仰铰链 —— 决定 BGT60TR13C 波束指向用户胸口的物理角度。**与雷达 IC 本身分开成模块**：IC 是雷达模块，支架是机械 + 可选位置反馈传感器模块。

主板：BY-SA-V001 / 项目：Lunawake (BY001)。

---

## 1. 模块定位

| 项 | 内容 |
|---|---|
| 用途 | 把 BGT60TR13C 主波束指向床上仰卧用户胸口（俯仰 / 方位） |
| 调节方式 | 当前 = **用户手动 + 锁死**；未来 = 可选电机驱动 + 闭环 |
| 与 [radar.md](radar.md) 关系 | radar.md 管 IC 电气 + 算法；本模块管**支架机械 + 角度 + 位置反馈** |
| 与 [industrial-design.md](industrial-design.md) 关系 | ID 文档定结构 / CMF；本文档定**电气接口 + 算法对接** |

## 2. 摆放几何（北美 SKU 已定，参见 [product-spec.md §5.0](product-spec.md)）

| 市场 | 床面距地 | 床头柜面 | 雷达高于胸口 | 推荐俯仰 |
|------|---------|---------|-----------|---------|
| **北美** | 61–76 cm（典型 63.5） | 58–71 cm | **+15 cm** | **−15°（固定）** |
| 亚洲 | 25–80 cm（跨度大） | 50–75 cm | −5 ~ +55 cm | **−10° / −25° / −40°（三档铰链）** 或软件校准 |

## 3. 当前结论：机械手动 + 锁死（来自 [选型对比](assets/霍尔开关_磁编码器_选型对比.md) §6）

**雷达上下摆动机构 = 用户手动调节 + 锁定后固定**，运行时不读取角度值。

| 方向 | 实现 |
|---|---|
| 上下调节（俯仰） | **无传感器**。改善重点：机械锁紧（弧形槽 + 蝶形螺母或双点锁紧），防振动跑位 |
| 左右调节（方位） | 同上，无传感器。如需用户参考，弧形槽旁刻角度刻度盘 |

> **决策依据**：用户校准后机构静态，不需要软件读角度。加传感器只会增加 BOM 和故障点。

→ 当前阶段 **不需要**电气接口；本节为机械 + ID 配合。

## 4. 未来电动化（可选，Phase 2+）

如果后续加入**电机驱动**（自动跟踪用户位置 / 软件辅助校准 / 多人房间扫描），则需位置反馈传感器：

### 4.1 候选 1：霍尔开关（限位 / 安全保护）

- **型号**：DRV5023A（TI）
- **用途**：检测机构到达上下两个**极限位置**，给电机断电保护
- **数量**：每轴 2 颗（上限位 + 下限位）
- **接口**：单 GPIO 数字输入（开漏 + 上拉）
- **电气**：3.3 V 供电，<10 mA
- **决策性质**：只判"到达 / 未到达"，不读连续角度

### 4.2 候选 2：磁编码器（连续角度反馈）

- **型号**：AS5600（ams OSRAM）
- **用途**：闭环角度读取（0–360°，12-bit 分辨率）
- **数量**：每轴 1 颗
- **接口**：I²C（占用 P4 已有 I²C 总线，配磁铁径向充磁）
- **电气**：3.3 V，~6 mA
- **决策性质**：知道"当前在哪个角度"并记录

### 4.3 何时各选

| 需求描述 | 推荐方案 |
|----------|----------|
| 只判断「是否到达某个固定位置」 | DRV5023 霍尔开关 |
| 需要知道「当前在哪个角度」并记录 | AS5600 磁编码器 |
| 全自动闭环跟踪 | DRV5023（限位安全） + AS5600（角度反馈），两颗并用 |

外围电路 / 安装注意事项详见 [选型对比 §4-5](assets/霍尔开关_磁编码器_选型对比.md)。

## 5. 雷达 IC 安装约束（影响 mount 设计）

雷达 IC 本身的安装硬约束在 [product-spec.md §5](product-spec.md)。Mount 模块负责落实：

- 雷达 IC 距顶壳 ≤ 8 mm（推荐），最大 15 mm
- 罩到 IC 距离 0 mm（贴合）或 ≥ 5 mm，**禁止 1–4 mm 之间**
- ±45° 主波束锥范围内**无任何金属 / 装饰条 / 加强筋 / 螺柱**
- 距喇叭磁铁 ≥ 50 mm

## 6. 验收（DVT）

按 [acceptance/dvt-gate.md §2 雷达罩首件验证](../progress/acceptance/dvt-gate.md) + 本模块特有项：

- [ ] 机械锁紧后 1.5 m 跌落地毯，角度不跑位
- [ ] 用户单手能完成俯仰调节，**不需要工具**
- [ ] 角度刻度盘读数清晰（如有）
- [ ] 北美 SKU −15° 固定档位，安装精度 ±2°
- [ ] 亚洲 SKU 三档（−10° / −25° / −40°）切换有 detent 段落感，每档精度 ±2°
